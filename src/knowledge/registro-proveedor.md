# Registro como proveedor

Las solicitudes identifican formato, campos y soportes. El glosario relaciona etiquetas con el maestro. Un valor sin fuente es faltante. En países distintos a Colombia se presenta el NIT con la nota de identificador extranjero y se solicita confirmación. Los soportes vencidos o ausentes bloquean el estado listo para firma; un campo faltante se informa pero no bloquea. Los datos bancarios se usan solo si se solicitan y no van en el borrador de correo. El agente no firma ni envía: únicamente prepara documentos y, tras confirmación humana inmediata, puede registrar una simulación de envío. Los portales no se automatizan en este reto.
